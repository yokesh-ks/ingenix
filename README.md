# Ingenix

> Tired of fixing your project structure later? Ingenix helps you get it right from the start.

---

## 🚀 What is Ingenix?

Ingenix helps you start your application with a **clean and scalable structure from day one**.

Instead of generating rigid templates, Ingenix creates projects that are:

* structured
* organized
* ready to grow

---

## 🤔 Why Ingenix?

Most developers face this problem:

* You start with a boilerplate
* As your app grows, the structure breaks
* You spend time refactoring instead of building

Ingenix solves this by helping you:

* start with the right foundation
* avoid messy restructuring later
* build with scalability in mind

---

## 🧠 How it works

Ingenix asks a few simple questions and sets up your project based on your choices.

```bash
npx ingenix create app
```
